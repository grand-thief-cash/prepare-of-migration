# German Phase 1 — A1 Zero-to-Beginner Detailed Plan

> 目标：从完全零基础开始，建立 A1 德语能力。
>
> 推荐周期：**8–10 周**
>
> 推荐投入：**每天 60–90 分钟**
>
> 核心教材：**DW Nicos Weg A1**
>
> 辅助工具：**Anki + Grammar Notes + Listening + Speaking**
>
> 最终验收：**Goethe-Zertifikat A1 官方模拟考试**

---

# 1. Phase 1 Goal

A1 结束时，不要求：

* 能流利聊天
* 能看德国新闻
* 能讨论复杂技术
* 能进行正式商务谈判

而要求：

> **能够使用简单德语完成基础日常沟通。**

---

# 5. Vocabulary Card Format

不要：

```text
Tisch = table
```

应该：

```text
der Tisch

Plural:
die Tische

Example:
Ich kaufe einen Tisch.
```

动词：

```text
arbeiten

Ich arbeite in Berlin.
```

固定表达：

```text
einen Termin vereinbaren

Ich möchte einen Termin vereinbaren.
```

---

```text

### Examples
```

# 8. Block 5 — Speaking

### 10 min

每天强迫自己说。

不要害怕错误。

例如今天学习：

```text
Arbeit
```

就自己说：

```text
Ich arbeite als Software Engineer.

Ich arbeite in ...

Ich arbeite mit Go.

Ich arbeite mit Python.

Ich lerne Deutsch.

Ich arbeite jeden Tag.
```

录音。

然后自己听。

# 14. Week 6 — Akkusativ + Practical Situations

重点：

```text

```


> 谁做动作？

# 32. End-of-Phase Project

A1 最后不要只做考试。

做一个：

> **German A1 Personal Project**

准备一段 2–3 分钟录音：

```text
Hallo.

Ich heiße ...

Ich komme aus ...

Ich wohne in ...

Ich arbeite als Software Engineer.

Ich arbeite mit ...

Ich lerne Deutsch, weil ...

In meiner Freizeit ...

Am Wochenende ...

Gestern habe ich ...

Nächstes Wochenende möchte ich ...

Vielen Dank.
```

然后：

1. 不看稿录音
2. 听自己的录音
3. 找出不会的表达
4. 修改
5. 再录一次

最终目标：

> **能够脱稿完成。**

这比单纯背一篇 A1 范文更有价值。

# 33. Final A1 Definition

最终把 A1 定义成：

> **I can survive in basic German.**

而不是：

> **I have finished a German textbook.**

也就是说：

```text
Learn
↓
Understand
↓
Remember
↓
Speak
↓
Use
↓
Test
```

完成这个闭环，才真正算完成 A1。
